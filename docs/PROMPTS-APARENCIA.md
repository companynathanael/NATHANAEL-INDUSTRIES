# Prompts de aparência — Fornalha

Prompts prontos para colar numa conversa nova e produzir **apenas a aparência** (site/painel)
de cada motor, seguindo o mesmo padrão visual do Asafe e do Gather.

---

## Prompt — FORNALHA

```
Crie apenas a APARÊNCIA (site/painel em HTML, CSS e JS, sem back-end) da FORNALHA, o 4º motor da Nathanael Industries.

PADRÃO VISUAL
- Siga exatamente o mesmo padrão de aparência do Asafe (repositório companynathanael/Asafe, index.html) e do Gather: mesma estrutura de layout, menu, cards, tipografia, espaçamentos e componentes.
- Mude somente as cores e o conteúdo.
- Cores: PRETO e LARANJA (sugestão: fundo #0A0A0A, laranja principal #F97316, laranja escuro #C2410C, texto #F5F5F5).
- Logo: fornalha com chama, branca sobre fundo preto (arquivo identidade/logos/fornalha.jpg do repositório companynathanael/NATHANAEL-INDUSTRIES).
- Use dados de demonstração (mock); nada precisa funcionar de verdade ainda.

QUEM É A FORNALHA
Motor de transformação. Numa fornalha, o metal derrete, se funde e é provado no fogo.
Fica entre o Gather e o Bezalel na linha de produção:
Gather (APIs) → FORNALHA (funde e prova) → Bezalel (molda a IA) → IA pronta. O Asafe sustenta tudo.

FUNÇÕES (cada uma vira uma tela/aba)
1. Painel geral: fornadas em andamento, habilidades fundidas, taxa de aprovação nas provas, alertas.
2. Fundição de habilidades: une várias APIs do Gather em uma habilidade pronta. Mostrar as APIs de entrada → habilidade de saída (ex.: cotação + gráfico + alerta → "Acompanhar ação").
3. Prova de fogo: fila de testes de habilidades e IAs novas sob pressão (situações difíceis, erros, sobrecarga), com status Em prova / Aprovado / Reprovado e o motivo.
4. Desempenho: velocidade, eficiência e consumo do que sai da fornalha; destaque para o que foi reprovado por lentidão ou desperdício.
5. Submotores (ainda não produzidos, mostrar como "em breve"): Fole (Continuidade), Fichário (Memória), Faísca (Autonomia).

NÃO FAZ: energia e infraestrutura (isso é do Asafe); criar IAs (isso é do Bezalel).
Textos em português.
```
